# Temporary integration branding

The repository's current icon and logo are original neutral placeholder artwork made for this integration. The square mark uses plain “F6” lettering and a simple Bluetooth cue; the landscape lockup adds the target name in ordinary sans-serif type. No official ForaCare artwork or stylized wordmark is included, and the assets do not claim manufacturer endorsement.

This temporary branding may be replaced with manufacturer branding if permission is obtained. The source artwork uses system fonts; no font files are included.
